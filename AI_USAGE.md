# Использование ИИ

Для разработки использовался Codex. При работе с Go применялись рекомендации
Modern Go Guidelines.

При этом была проведена проверка предложенного ИИ кода на соответствие требованиям задания, разобрана его логика и вручную воспроизведены основные сценарии работы программы. По результатам проверки были исправлены найденные ошибки и упрощались отдельные решения. После изменений запускались тесты и проверялась сборка. ИИ помогал с реализацией и поиском вариантов, а окончательные решения я принимал после проверки и понимания предложенного кода.
